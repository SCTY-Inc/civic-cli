One search across policy sources.

civic-cli is an open-source command-line tool and Python library that searches US bills, rules, dockets, court opinions and state legislation in one call. It is for people and agents who need to show where each result came from. Every record carries its source, the request, the HTTP status, the time and a content hash.

The output is the record

civic keeps nothing between runs. Each run returns one envelope. In JSONL, the first line lists every call the run made and every error, and each line after it is one record. Saved to a file, that envelope is a complete account of the search. Add --raw-dir to keep each raw response as well.

Quickstart

civic needs Python 3.11 or later and has two dependencies, httpx and python-dotenv. It makes no model calls.

uv tool install git+https://github.com/SCTY-Inc/civic-cli
civic doctor
civic search "respite care" --sources federal_register --format jsonl

The Federal Register needs no key. GovInfo, Regulations.gov, Open States, LegiScan and Exa each need an API key, and Exa charges per request. Export the keys in your shell before you run civic. civic doctor shows which sources can run. In our test on 15 November 2026 without keys, only the Federal Register answered. CourtListener returned 401, Semantic Scholar returned 429, and Census did not return JSON.

Why

If an agent tells you a bill moved, can you check where it read that?

civic used to do more. It had a Gemini pipeline that researched, wrote and reviewed reports, with presets, a compare mode and a cache. In October 2026 all of that came out, and the code went from 2,744 lines to 1,176. What stayed is the part a caller cannot rebuild later: an adapter for each source and a record that carries its own provenance.

A source that fails does not stop the search. Its error goes into errors[] next to the records from sources that answered. In our test, civic doctor listed CourtListener as ready because it needs no key, but the service now refuses requests without a token. The run still finished and recorded the 401.

If you delete it tomorrow, you lose nothing

The envelopes and raw responses you saved are ordinary JSON files, and each record links to its official source. The data stays under each provider's terms.
